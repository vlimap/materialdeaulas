# HTML5 — Aula 06: Formulários II

**Duração:** 4 horas. **Cenário:** Revisar pré-inscrição fictícia com validação nativa.

## Como executar

1. Abra `index.html` no navegador (ou use a extensão Live Server no VS Code).
2. Faça as alterações indicadas no roteiro e salve o arquivo.
3. Atualize a página, teste a navegação apenas com teclado e valide o HTML.

## Atividades
1. Crie um campo number com min e max.
2. Acrescente date para o dia de interesse.
3. Teste formulário vazio, entrada inválida e válida.
4. Observe as mensagens nativas, sem usar dados reais.

## Critérios de conclusão
- [ ] Todos os controles têm label ou legend.
- [ ] Entradas fora dos limites acionam validação nativa.
- [ ] O formulário pode ser usado apenas com teclado.
- [ ] Nenhum dado real é armazenado ou enviado a terceiros.

Este laboratório usa conteúdo fictício. Não insira dados pessoais reais. Documentação: https://html.spec.whatwg.org/multipage/ e https://www.w3.org/WAI/tutorials/.
