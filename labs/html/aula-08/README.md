# HTML5 — Aula 08: Imagens responsivas

**Duração:** 4 horas. **Cenário:** Monte a galeria responsiva de projetos da comunidade.

## Como executar

1. Abra `index.html` no navegador (ou use a extensão Live Server no VS Code).
2. Faça as alterações indicadas no roteiro e salve o arquivo.
3. Atualize a página, teste a navegação apenas com teclado e valide o HTML.

## Atividades
1. Abra o exemplo no navegador em larguras de 375 e 1024 pixels.
2. Inclua uma segunda imagem com srcset e sizes.
3. Use alt descritivo, width e height em ambas.
4. Observe a escolha da fonte nas ferramentas de rede do navegador.

## Critérios de conclusão
- [ ] Toda imagem informativa tem alt apropriado.
- [ ] O navegador encontra recursos existentes em srcset.
- [ ] A página reserva proporções com width e height.
- [ ] A visualização permanece legível em telas pequenas.

Este laboratório usa conteúdo fictício. Não insira dados pessoais reais. Documentação: https://html.spec.whatwg.org/multipage/ e https://www.w3.org/WAI/tutorials/.
