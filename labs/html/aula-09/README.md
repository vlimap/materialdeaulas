# HTML5 — Aula 09: Acessibilidade HTML

**Carga horária:** 4h. **Projeto:** Audite e melhore uma página de atendimento

## Instruções

Abra `index.html` no navegador ou no VS Code Web. Execute estas etapas:

1. Teste a página usando somente Tab, Enter e Espaço.
2. Adicione uma imagem informativa com alt e dimensões.
3. Inclua ajuda ao campo do formulário com aria-describedby.
4. Verifique contraste visual e hierarquia de heading.

## Entrega e revisão

- [ ] A página tem lang e conteúdo principal identificável.
- [ ] Links, botões e expansão funcionam com teclado.
- [ ] Imagens informativas têm texto alternativo adequado.
- [ ] Campos têm rótulos e instruções compreensíveis.

**Segurança:** o conteúdo é educacional e fictício; não preencha dados pessoais reais. Utilize https://validator.w3.org/nu/ para conferir a marcação.
