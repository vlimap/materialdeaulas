# HTML5 — Aula 12: Projeto final

**Carga horária:** 4h. **Projeto:** Conclua um site de biblioteca com três páginas

## Instruções

Abra `index.html` no navegador ou no VS Code Web. Execute estas etapas:

1. Edite index.html, agenda.html e contato.html com conteúdo fictício.
2. Verifique todos os links relativos e a consistência da navegação.
3. Inclua horários como tabela e formulário demonstrativo em páginas apropriadas.
4. Registre resultado da verificação HTML, teclado e tamanhos de tela.

## Entrega e revisão

- [ ] Três páginas HTML existem e todos os links internos funcionam.
- [ ] Conteúdo principal, títulos, landmarks e metadados são coerentes.
- [ ] Agenda tem tabela acessível e Contato não coleta dados reais.
- [ ] Uma revisão registra testes, limitações e melhorias futuras.

**Segurança:** o conteúdo é educacional e fictício; não preencha dados pessoais reais. Utilize https://validator.w3.org/nu/ para conferir a marcação.
