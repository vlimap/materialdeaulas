# Projeto final — avaliação de qualidade

| Critério | Evidência esperada |
| --- | --- |
| Três páginas | index.html, agenda.html, contato.html |
| Navegação | Todos os links relativos funcionam e página atual é indicada |
| Semântica | lang, h1/h2, main, nav, header/footer conforme contexto |
| Tabela | caption e th com scope, sem layout tabular |
| Formulário | Label e fieldset quando necessário, sem transmissão real |
| Acessibilidade | Teste de teclado, leitura linear e textos alternativos |
| SEO | Title e description exclusivos |
| Código | Marcação validada e texto verificável |

## Rubrica (0 a 2 por critério)

0 = ausente; 1 = parcial/com erro; 2 = completo/testado. Total máximo: **16 pontos**. Critério de aprovação sugerido: **13/16**, sem falhas críticas de navegação e acessibilidade.
