# HTML5 — Aula 10: SEO e metadados

**Carga horária:** 4h. **Projeto:** Prepare a página pública fictícia de uma biblioteca

## Instruções

Abra `index.html` no navegador ou no VS Code Web. Execute estas etapas:

1. Personalize o title e description para a página real do exercício.
2. Inclua og:image apenas se houver um arquivo publicamente acessível.
3. Escreva JSON-LD Organization com dados fictícios coerentes.
4. Valide HTML e JSON antes de considerar publicável.

## Entrega e revisão

- [ ] title e description têm conteúdo relevante e não duplicado.
- [ ] canonical de exemplo não é tratado como URL real de produção.
- [ ] JSON-LD é válido e descreve fatos presentes na página.
- [ ] Não há promessas de ranking nem dados fictícios apresentados como reais.

**Segurança:** o conteúdo é educacional e fictício; não preencha dados pessoais reais. Utilize https://validator.w3.org/nu/ para conferir a marcação.
