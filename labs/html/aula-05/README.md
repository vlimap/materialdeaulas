# HTML5 — Aula 05: Formulários I

Este laboratório ensina labels, tipos de campos, fieldset e legend, sem envio real para servidor. Use dados fictícios.

## Atividades

1. Acrescente um seletor `select` para o tema da oficina.
2. Inclua `textarea` identificado por `label`.
3. Agrupe escolhas exclusivas com radio de mesmo `name` e `fieldset`.
4. Teste Tab, Espaço, setas e Enter.

## Aceite

- [ ] Todo campo possui rótulo visível e único.
- [ ] Grupos de opções possuem legendas.
- [ ] A página funciona sem CSS e sem mouse.
- [ ] Nenhum dado pessoal real é enviado.
