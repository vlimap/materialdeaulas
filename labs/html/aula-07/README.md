# HTML5 — Aula 07: Mídia e incorporações

**Duração:** 4 horas. **Cenário:** Crie uma página de aula com mídia e transcrição.

## Como executar

1. Abra `index.html` no navegador (ou use a extensão Live Server no VS Code).
2. Faça as alterações indicadas no roteiro e salve o arquivo.
3. Atualize a página, teste a navegação apenas com teclado e valide o HTML.

## Atividades
1. Insira um vídeo próprio de teste como midia/aula.mp4 ou mantenha a mensagem explicativa.
2. Edite legendas-pt.vtt de acordo com a duração do vídeo.
3. Escreva uma transcrição que faça sentido sem reproduzir a mídia.
4. Teste a navegação com Tab e sem acesso à Internet.

## Critérios de conclusão
- [ ] A pessoa escolhe quando reproduzir áudio e vídeo.
- [ ] iframe tem title e restrições adequadas.
- [ ] Legendas e transcrição estão previstas e legíveis.
- [ ] Ausência de mídia local é explicada sem impedir a leitura.

Este laboratório usa conteúdo fictício. Não insira dados pessoais reais. Documentação: https://html.spec.whatwg.org/multipage/ e https://www.w3.org/WAI/tutorials/.
