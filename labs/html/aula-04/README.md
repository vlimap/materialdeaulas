# HTML5 — Aula 04: Tabelas acessíveis

**Duração:** 4 horas. **Cenário:** Monte a tabela de horários de uma biblioteca.

## Como executar

1. Abra `index.html` no navegador (ou use a extensão Live Server no VS Code).
2. Faça as alterações indicadas no roteiro e salve o arquivo.
3. Atualize a página, teste a navegação apenas com teclado e valide o HTML.

## Atividades
1. Preencha pelo menos mais duas linhas em tbody.
2. Insira um tfoot quando houver informação de síntese.
3. Leia os cabeçalhos em voz alta na ordem de navegação.
4. Valide a marcação com o validador HTML do W3C.

## Critérios de conclusão
- [ ] A tabela possui caption descritivo.
- [ ] th indica cabeçalhos de linha ou coluna com scope.
- [ ] Dados são coerentes e não representam layout.
- [ ] Navegação e leitura fazem sentido sem CSS.

Este laboratório usa conteúdo fictício. Não insira dados pessoais reais. Documentação: https://html.spec.whatwg.org/multipage/ e https://www.w3.org/WAI/tutorials/.
