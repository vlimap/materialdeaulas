# Aula 03 — HTML semântico

Prática de 45 minutos: edite `index.html` sem CSS ou JavaScript.

1. Adicione um segundo `article` com título e `time datetime`.
2. Acrescente uma `figure` com `figcaption`.
3. Teste os links internos e a navegação por teclado.
4. Confira que `main` é único e `aside` é complementar.
5. Valide o arquivo no Nu HTML Checker.

Referências: https://html.spec.whatwg.org/multipage/sections.html e https://validator.w3.org/nu/.
