# HTML5 — Aula 11: HTML moderno

**Carga horária:** 4h. **Projeto:** Monte uma central interativa com HTML nativo

## Instruções

Abra `index.html` no navegador ou no VS Code Web. Execute estas etapas:

1. Teste details e popover somente com teclado.
2. Inclua meter para ocupação fictícia de 20 de 30 vagas.
3. Adicione um bloco data-category apropriado.
4. Explique o que template faz sem JavaScript.

## Entrega e revisão

- [ ] O conteúdo expansível funciona sem script.
- [ ] O popover tem rótulo claro no botão.
- [ ] progress e meter correspondem ao significado dos dados.
- [ ] Nenhum conteúdo essencial depende de hidden ou template.

**Segurança:** o conteúdo é educacional e fictício; não preencha dados pessoais reais. Utilize https://validator.w3.org/nu/ para conferir a marcação.
