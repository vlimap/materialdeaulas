# Código de conduta

Este é um projeto de aprendizagem aberto. Participe com respeito, paciência e disposição para ensinar e aprender.

Não serão aceitos assédio, discriminação, ataques pessoais, exposição de dados privados, plágio ou comportamento que impeça outras pessoas de contribuir.

Ao revisar uma contribuição, critique o código, o conteúdo ou a decisão — nunca a pessoa. Prefira perguntas, exemplos e sugestões concretas.

Para relatar um problema de conduta, abra uma issue privada no repositório ou entre em contato com o mantenedor pelo perfil do projeto.
